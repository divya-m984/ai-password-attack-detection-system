## Known limitations

- Feature names describe observations and deviations, never conclusions. No column asserts that an attack occurred.
- Ground-truth labels, campaign metadata, and split assignments are absent by construction and are rejected at catalog build time.
- Baseline-derived features are null for entities absent from the fitted baseline; they are not silently treated as novel.
- Synthetic data exercises these features but does not demonstrate real-world detection effectiveness.
